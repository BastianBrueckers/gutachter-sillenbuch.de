# Gutachter Sillenbuch

Statische Website für **gutachter-sillenbuch.de**.

## Veröffentlichung

Die Website ist für die Veröffentlichung über **GitHub Pages** vorbereitet. Sie benötigt keinen Build-Prozess: GitHub Pages kann die Dateien direkt aus dem Repository ausliefern.

## Ordnerstruktur

```text
/
├── index.html
├── impressum.html
├── datenschutz.html
├── CNAME
├── css/
├── js/
├── images/
├── faq/
└── ratgeber/
```

## Custom Domain

Die Datei `CNAME` wird von GitHub Pages für die Custom Domain benötigt und enthält exakt:

```text
gutachter-sillenbuch.de
```

Wenn die Domain in GitHub Pages aktiviert wird, sollte zusätzlich geprüft werden, ob die DNS-Einträge beim Domainanbieter korrekt auf GitHub Pages zeigen und ob HTTPS erzwungen ist.
